Jump Jump Jimbo and Friends

A fun, fast-paced jumping game where Jimbo and his friends attempt to escape from a dangerous planet!

🎮 About the Game

Jump Jump Jimbo and Friends is an arcade-style platforming game built around timing, precision and survival. Choose your planet, take control of your character, and see how high you can climb while escaping the dangers below.

Each run focuses on escaping a single planet, with different planetary themes offering their own atmosphere and visual identity.

🚀 Features

- Choose Your Planet — Select the planet you want to escape before starting a run.
- Endless Climb — Jump upwards through an increasingly challenging environment.
- Dynamic Platforms — Navigate platforms with varied layouts and carefully designed jumps.
- Hazards and Obstacles — React quickly to survive as the challenge increases.
- Jimbo and Friends — A cast of characters bringing personality to the game.
- Shared Leaderboard — Compete for high scores and show which planet you escaped from.
- Score Tracking — Challenge yourself to beat your previous best.

🕹️ How to Play

1. Choose a planet.
2. Start your escape attempt.
3. Jump between platforms and avoid hazards.
4. Climb as high as possible.
5. Try to beat your best score and compete on the shared leaderboard.

🌍 The Planets

Each run takes place on the planet selected at the beginning. Your goal is to escape that planet rather than travel between multiple planets during a single run.

🛠️ Development

This repository contains the source files for Jump Jump Jimbo and Friends.

The game is being developed as a browser-based game using HTML, CSS and JavaScript.

📦 Running the Game Locally

1. Download or clone this repository.
2. Open "index.html" in a web browser.
3. Start playing!

If the game uses additional assets or files, keep the repository's folder structure intact.

🌐 Play Online

The game can be hosted using GitHub Pages once the repository has been configured for deployment.
